# Mi primer proyecto Android

Pantalla de bienvenida para Android (Java) que muestra:

- **a) Idiomas:** español (por defecto), inglés, francés y alemán (`values`, `values-en`, `values-fr`, `values-de`).
- **b) Tamaños de pantalla y orientación:** `ConstraintLayout` con guías porcentuales, `layout-land` para horizontal y `dimens` distintos para `sw600dp` (tablet 7") y `sw720dp` (tablet 10" / TV).
- **c) Imagen de fondo nine-patch:** `drawable-nodpi/fondo_nube.9.png`, que se estira sin deformar las nubes.

## Cómo abrirlo
1. Clona el repositorio.
2. En Android Studio: *File > Open* y selecciona la carpeta.
3. Espera la sincronización de Gradle y ejecuta en el emulador.
